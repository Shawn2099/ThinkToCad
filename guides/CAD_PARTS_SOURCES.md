# CAD_PARTS_SOURCES.md — Where to Find Pre-Made CAD Models, Mechanisms, and Parts

A curated list of sources for ready-to-use CAD models, mechanisms, parts, and
assemblies that you can download and use in your designs. Organized by category.
All URLs verified as of 2026.

> Use these to avoid reinventing the wheel. Always check the license before
> using in commercial products.

## How to use this list with ThinkToCad

1. **For standard parts** (fasteners, bearings, gears): Download STEP from McMaster-Carr or step.parts, import into FreeCAD/build123d.
2. **For mechanisms**: Search GrabCAD or Thingiverse for existing mechanism designs. Verify before using (quality varies).
3. **For manufacturer components**: Use TraceParts or manufacturer CAD libraries for accurate models of purchased parts.
4. **For parametric parts**: Use OpenSCAD/CadQuery/build123d to generate parametric models.
5. **For research/validation**: Use NIST/ABC/DeepCAD datasets for AI training and validation.

## License reminder

- **CC0 / Public domain**: Use freely, no attribution needed.
- **CC-BY**: Use freely with attribution.
- **CC-BY-SA**: Use freely with attribution, share derivatives under same license.
- **MIT/Apache**: Use freely with attribution, share derivatives under same license.
- **Manufacturer CAD**: Usually free for design use but not for redistribution.
- **GrabCAD community**: Varies by uploader; check individual model license.
- **Research datasets**: Usually research-use only; check terms before commercial use.

## AI rules for using pre-made CAD

1. Always check the license before using in a commercial product.
2. Verify the model geometry (watertight, correct dimensions) before using.
3. Prefer STEP format for interoperability (FreeCAD, build123d, SolidWorks, Fusion).
4. For standard parts, prefer manufacturer models over community models (more accurate).
5. For mechanisms, study the design but build your own (understand the mechanism, don't just copy).
6. Keep a source attribution file in your project for all downloaded models.
