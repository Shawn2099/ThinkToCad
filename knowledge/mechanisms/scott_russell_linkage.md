# scott_russell_linkage
**Type:** mechanism
**Function:** Produce exact straight-line motion from a sliding input.

## How it works
Sliding input drives links arranged per Scott Russell geometry to an exact straight line.

## Key dimensions / equations
- Link geometry per Scott Russell.

## Constraints
- Sliding friction.
- Space.

## Failure modes
- Slider wear.
- Binding.

## When to use
Steam engines, straight-line guides.

## DFM (small workshop)
Use linear bearings; lubricate.
