# sleeve_coupling

**Type:** coupling
**Function:** Connect two shafts with a single cylindrical sleeve bored to fit both ends.

## How it works
A one-piece sleeve (muff) is keyed or set-screwed to both shafts, acting as a single shaft. High torque for size; zero backlash.

## Key dimensions / equations
- Torque limited by key/bore shear.
- Sleeve length and diameter set stiffness.
- Alignment must be held (rigid).

## Constraints
- No misalignment accommodation.
- Difficult to install/remove on long shafts.
- Requires precise alignment.

## Failure modes
- Key shear.
- Fretting at interface.
- Bearing damage from misalignment.

## When to use
Vertical pumps, turbines, low-cost well-aligned drives.

## DFM (small workshop)
Use keyed + set-screw; ensure alignment; consider split type for serviceability.
