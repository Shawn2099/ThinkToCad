# cam
**Type:** mechanism
**Function:** Convert rotary input to programmed follower motion via cam profile.

## How it works
Cam profile dictates follower displacement as cam rotates; follower type affects stress and wear.

## Key dimensions / equations
- Base circle, lift, pressure angle, follower type.

## Constraints
- Wear; Hertz stress; design complexity.

## Failure modes
- Follower jump.
- Wear; fatigue.

## When to use
Complex motion profiles, valve timing, automation.

## DFM (small workshop)
Use roller followers; harden cam; lubricate.
