# quick_return_crank_shaper
**Type:** mechanism
**Function:** Provide reciprocating motion with return stroke faster than cutting stroke via slotted lever.

## How it works
Crank pin drives a slotted lever; lever oscillates and carries the tool at its end.

## Key dimensions / equations
- Crank radius; lever length.
- Time ratio up to ~2.5:1.

## Constraints
- Slot wear.
- Limited ratio; impact at reversal.

## Failure modes
- Slot elongation.
- Pin wear.

## When to use
Shapers, slotters, machine tools.

## DFM (small workshop)
Use hardened slot liners; lubricate; check pin fit.
