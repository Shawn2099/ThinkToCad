# follower_oscillating
**Type:** mechanism
**Function:** Oscillating (rocker) follower driven by cam.

## How it works
Cam acts on lever; follower rocks about pivot.

## Key dimensions / equations
- Lever length; pivot location; cam lift.

## Constraints
- Limited arc; pivot wear.

## Failure modes
- Pivot wear.
- Impact.

## When to use
Valve trains, automation.

## DFM (small workshop)
Use bushings; lubricate.

## Sources
- Standard classification (Norton/Shigley).
