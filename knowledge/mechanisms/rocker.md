# rocker
**Type:** mechanism
**Function:** Simple lever rotating about a pivot to amplify or redirect force/motion.

## How it works
Lever arm pivots about a fixed axis; input at one arm produces output at the other.

## Key dimensions / equations
- Arm lengths; pivot location.
- Mechanical advantage = arm ratio.

## Constraints
- Limited travel.
- Pivot friction.

## Failure modes
- Pivot wear.
- Bending if overloaded.

## When to use
Pedals, valves, controls.

## DFM (small workshop)
Use bushings; reinforce arms.
