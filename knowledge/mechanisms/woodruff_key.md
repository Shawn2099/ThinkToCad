# woodruff_key

**Type:** fastener
**Function:** Semicircular (half-moon) key that seats in curved keyseat; self-aligning - [Engineering Hardware](https://engineeringhardware.com/); [Cromwell](https://www.cromwell.co.uk/shop/fasteners-and-fixings/rivets-pins-and-keys/c/2342).

## How it works
Semicircular (half-moon) key that seats in curved keyseat; self-aligning - [Engineering Hardware](https://engineeringhardware.com/); [Cromwell](https://www.cromwell.co.uk/shop/fasteners-and-fixings/rivets-pins-and-keys/c/2342).

## Key dimensions / equations
- Moderate torque; good in tapered shafts.

## Constraints
- Weaker than square key for same size
- keyseat weakens shaft.

## Failure modes
- Weaker than square key for same size; keyseat weakens shaft.

## When to use
- Applications: Tapered shafts, automotive, machine tools.
- Select when: Tapered shafts, easy assembly, moderate torque.
- Advantages: Self-aligning, stays in shaft during assembly, good for tapers.

## DFM (small workshop)
Use standard parts and simple tooling; verify fit and tolerances in the small workshop.
