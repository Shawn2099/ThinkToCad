# follower_spherical
**Type:** mechanism
**Function:** Follow cam profile with spherical tip to accommodate misalignment.

## How it works
Spherical tip contacts cam; allows angular misalignment.

## Key dimensions / equations
- Radius; load capacity; misalignment tolerance.

## Constraints
- Lower load capacity than cylindrical.

## Failure modes
- Wear; pitting.

## When to use
Moderate load with misalignment.

## DFM (small workshop)
Use hardened sphere; lubricate.

## Sources
- Standard classification (Norton/Shigley).
