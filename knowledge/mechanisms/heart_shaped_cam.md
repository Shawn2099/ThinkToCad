# heart_shaped_cam
**Type:** mechanism
**Function:** Return a shaft to a set position by roller pressure via symmetric heart profile.

## How it works
Heart-shaped cam rotates; roller follower returns shaft to set position.

## Key dimensions / equations
- Heart profile; roller radius.

## Constraints
- Wear; precision.

## Failure modes
- Profile wear.
- Roller flat-spotting.

## When to use
Synchronization (early master clocks).

## DFM (small workshop)
Harden profile; use roller follower.
