# harmonic_drive
**Type:** mechanism
**Function:** High-ratio zero-backlash compact drive via strain wave gearing.

## How it works
Wave generator deforms flex spline into circular spline; 2-tooth difference yields high ratio.

## Key dimensions / equations
- Flex spline teeth; circular spline teeth.
- Ratio = (flex - circular)/flex.

## Constraints
- Torsional wind-up.
- Cost; flex spline fatigue.

## Failure modes
- Flex spline fatigue.
- Bearing wear.

## When to use
Robotics, aerospace.

## DFM (small workshop)
Use commercial units; protect from shock.
