# parallelogram_linkage
**Type:** mechanism
**Function:** Keep a coupler link translating without rotation using equal, parallel opposite links.

## How it works
Four-bar with opposite links equal and parallel; input crank drives the coupler, which stays parallel to ground.

## Key dimensions / equations
- Equal link lengths; parallelogram geometry.
- Stroke limited by joint travel.

## Constraints
- Bulky.
- Requires parallelism; joint clearances affect accuracy.

## Failure modes
- Joint wear causes skew.
- Long links buckle under load.

## When to use
Maintain orientation during motion; drafting arms; suspensions.

## DFM (small workshop)
Use equal-length stock bars; pin joints with bushings; check parallelism.
