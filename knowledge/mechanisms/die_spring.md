# die_spring

**Type:** spring
**Function:** Provide heavy-duty compression springing for dies, clutches, brakes, and machinery.

## How it works
A heavy-duty helical compression spring, often color-coded by load range, designed for high loads and long life in tooling and machinery.

## Key dimensions / equations
- Rate k = G d^4 / (8 D^3 N_a) (helical compression).
- Solid height and free length define travel.
- Color code indicates load range (manufacturer).

## Constraints
- Space and solid height limit travel.
- High loads require proper seating and guidance.
- Fatigue life depends on stress range.

## Failure modes
- Fatigue fracture.
- Buckling if unsupported.
- Permanent set from overload.

## When to use
Dies, clutches, brakes, farm/aircraft mechanisms, heavy machinery.

## DFM (small workshop)
Select by color-coded load rating; use spring guides/seats; verify solid height.
