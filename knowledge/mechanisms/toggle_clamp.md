# toggle_clamp

**Type:** indexing
**Function:** Provide self-locking clamping/hold-down force via an over-center linkage.

## How it works
Over-center linkage (draw latch) passes through dead center; holding force amplified by leverage. Self-locking when toggle is beyond center and load keeps it there; release by pushing past center. Used in jigs, fixtures, molds.

## Key dimensions / equations
- Toggle positions occur when links are collinear (four-bar).
- Mechanical advantage -> inf near toggle; force-to-effort ratio high.
- Must pass clearly over center to self-lock.

## Constraints
- Release requires pushing past center.
- Accidental release possible if not clearly over center under vibration.
- Force-multiplication ratios vendor-specific.

## Failure modes
- Accidental release under vibration if not over center.
- Link/pivot wear.
- Overload bending of links.

## When to use
Jigs, fixtures, molds, workholding, quick clamping.

## DFM (small workshop)
Ensure toggle passes clearly over center, add stops, guard pinch points, use commercial units.
