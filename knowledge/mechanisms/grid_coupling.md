# grid_coupling

**Type:** coupling
**Function:** Transmit high torque through a serpentine steel grid spring between grooved hubs.

## How it works
A tapered steel grid spring sits in grooves of two hubs, transmitting torque while flexing to absorb shock/vibration and misalignment. Lubricated; grid replaceable.

## Key dimensions / equations
- Torque capacity very high (up to ~932,000 Nm in large sizes).
- Grid deflection provides torsional compliance.
- Speeds up to ~6,000 rpm (size-dependent).

## Constraints
- Requires lubrication.
- Moderate misalignment (less than elastomeric).
- Maintenance needed.

## Failure modes
- Grid wear/fatigue.
- Lubrication breakdown.
- Hub groove wear.

## When to use
Pumps, blowers, compressors, conveyors, marine, heavy industry.

## DFM (small workshop)
Use commercial units; grease per spec; replace grid as wear part.
