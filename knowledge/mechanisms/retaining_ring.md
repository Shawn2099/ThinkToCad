# retaining_ring

**Type:** fastener
**Function:** Provide axial retention of bearings/gears on shafts or in bores via a spring-steel ring in a groove.

## How it works
A spring-steel ring (circlip/snap ring) is seated in a machined groove, creating a shoulder that retains a component axially. External (shaft) rings (DIN 471) and internal (bore) rings (DIN 472).

## Key dimensions / equations
- DIN 471 = external (shaft) circlips; DIN 472 = internal (bore) circlips.
- Size range: shaft O3-300 mm; bore O8-400 mm.
- Groove dimensions per standard (width/depth) to suit ring.

## Constraints
- Groove weakens shaft/bore; avoid in high-stress sections.
- Requires groove machining access.
- Ring must be seated fully; partial seating causes failure.

## Failure modes
- Ring ejection under axial overload.
- Groove deformation/wear.
- Corrosion or fatigue of spring steel.

## When to use
Bearing/gear retention, shaft shoulders replacement, compact axial location.

## DFM (small workshop)
Use standard DIN rings, machine grooves with standard tooling, ensure full seating, add lubrication.
