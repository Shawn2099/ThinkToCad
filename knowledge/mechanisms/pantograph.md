# pantograph
**Type:** mechanism
**Function:** Scale and copy planar motion/paths using a parallelogram linkage.

## How it works
Parallelogram linkage with a fixed pivot; tracer point motion is scaled to the pen point.

## Key dimensions / equations
- Scale ratio from link lengths.

## Constraints
- Friction; accuracy; size; stiffness.

## Failure modes
- Joint backlash.
- Link flex.

## When to use
Copying, engraving, scaling drawings, current collectors.

## DFM (small workshop)
Use rigid links and low-friction pivots; minimize backlash.
