# peaucellier_lipkin
**Type:** mechanism
**Function:** Produce exact straight-line motion from rotary input using an eight-bar linkage.

## How it works
Eight-bar linkage with specific link length relations (inversion circle); coupler point traces a perfect straight line.

## Key dimensions / equations
- Inversion circle radius.
- Link length relations.

## Constraints
- Complex; many joints; friction; cost.

## Failure modes
- Joint wear accumulates error.
- Binding.

## When to use
Precision instruments (historical).

## DFM (small workshop)
Use precision pins/bushings; minimize backlash.
