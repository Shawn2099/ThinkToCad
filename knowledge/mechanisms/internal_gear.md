# internal_gear
**Type:** mechanism
**Function:** Nested gear with teeth pointing inward; same rotation sense as pinion.

## How it works
Internal gear meshes with external pinion; both rotate same sense.

## Key dimensions / equations
- Module, teeth count, ratio.

## Constraints
- Pinion size limits.
- Manufacturing.

## Failure modes
- Tooth wear.
- Assembly errors.

## When to use
Planetary ring gears; compact drives.

## DFM (small workshop)
Use standard gear cutters; check clearance.
