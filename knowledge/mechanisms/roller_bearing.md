# roller_bearing

**Type:** bearing
**Function:** Carry higher radial (and/or combined) loads than ball bearings using line contact.

## How it works
Rolling elements are cylinders/needles/tapers instead of balls, giving line contact and higher load capacity. Variants: cylindrical roller, tapered roller, needle roller. Life exponent p = 10/3.

## Key dimensions / equations
- Basic rating life L10 = (C/P)^(10/3) million revolutions (roller bearings).
- C = basic dynamic load rating; P = equivalent dynamic load.
- Tapered rollers handle combined radial+thrust; cylindrical rollers handle radial only.
- Fits per ISO 286 tolerance zones.

## Constraints
- Less tolerant of misalignment (except spherical rollers).
- Higher friction than ball bearings.
- Requires precise alignment and lubrication.

## Failure modes
- Fatigue pitting, roller skewing, edge loading.
- Lubrication breakdown causing seizure.
- Misalignment-induced wear.

## When to use
High radial loads, gearboxes, wheel hubs, heavy machinery.

## DFM (small workshop)
Use tapered rollers for combined loads; align carefully; lubricate with oil/grease per speed.
