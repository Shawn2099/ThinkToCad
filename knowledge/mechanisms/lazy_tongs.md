# lazy_tongs
**Type:** mechanism
**Function:** Amplify reach with folding scissor-like parallelogram segments.

## How it works
Multiple parallelogram segments fold/extend; small input motion yields long reach.

## Key dimensions / equations
- Number of segments.
- Extension ratio.

## Constraints
- Low stiffness.
- Buckling; joint friction.

## Failure modes
- Buckling under load.
- Joint wear.

## When to use
Reaching aids, compact stowage, clamps.

## DFM (small workshop)
Use tubular links; pin joints with bushings.
