# cycloidal_drive
**Type:** mechanism
**Function:** High-torque compact reducer with zero backlash.

## How it works
Eccentric input drives cycloidal disc; disc meshes stationary ring gear; output pins.

## Key dimensions / equations
- Reduction r = (P - L)/L.
- Efficiency ~93% single, ~86% double.

## Constraints
- Vibration if unbalanced; use 2+ discs.

## Failure modes
- Bearing wear.
- Pin wear.

## When to use
Robotics actuators, high-torque compact reducers.

## DFM (small workshop)
Use commercial units; balance discs.
