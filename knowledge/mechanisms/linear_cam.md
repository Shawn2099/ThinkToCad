# linear_cam
**Type:** mechanism
**Function:** Convert linear input to programmed output via profile cut in moving element.

## How it works
Cam element moves in straight line; followers (pins) ride profile/slots.

## Key dimensions / equations
- Profile geometry; stroke.

## Constraints
- Sliding friction; wear.

## Failure modes
- Profile wear.
- Binding.

## When to use
Pin-tumbler locks, key duplication.

## DFM (small workshop)
Harden profile; lubricate.
