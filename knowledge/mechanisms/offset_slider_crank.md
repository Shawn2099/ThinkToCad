# offset_slider_crank
**Type:** mechanism
**Function:** Convert rotary to linear motion with slider axis offset from crank center to reduce side thrust.

## How it works
Crank drives connecting rod; slider axis is offset by eccentricity e from crank center.

## Key dimensions / equations
- Crank radius r; rod length l; offset e.
- Stroke = 2r.

## Constraints
- Asymmetric motion.
- Offset must satisfy geometry (e < r + l).

## Failure modes
- Side-thrust wear.
- Binding if offset too large.

## When to use
Small engines/pumps needing smoother side thrust.

## DFM (small workshop)
Bore offset carefully; use bronze bushings; lubricate.
