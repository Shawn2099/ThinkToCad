# preloaded_cam
**Type:** mechanism
**Function:** Maintain follower contact via spring preload to avoid jump.

## How it works
Spring preloads follower against cam profile.

## Key dimensions / equations
- Preload force; spring rate; cam speed.

## Constraints
- Spring fatigue; contact stress.

## Failure modes
- Spring failure.
- Follower jump at high speed.

## When to use
High-speed open cams.

## DFM (small workshop)
Select spring with adequate fatigue life.

## Sources
- Standard practice (unverified).
