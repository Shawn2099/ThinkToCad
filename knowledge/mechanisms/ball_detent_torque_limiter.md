# ball_detent_torque_limiter

**Type:** coupling
**Function:** Disengage at overload via balls rolling out of detents, re-engaging at set position with minimal backlash.

## How it works
Balls in detents transmit torque; on overload balls roll out, separating drive. Re-engages at set angular position. Backlash-free variants available.

## Key dimensions / equations
- Release torque set by spring preload and ball/detent geometry.
- Idle-rotation versions for high inertia.
- Repeatability high.

## Constraints
- More complex and costly.
- Ratcheting wear if not monitored.
- Requires reset/alignment.

## Failure modes
- Ball/detent wear.
- Spring fatigue.
- Misalignment after release.

## When to use
Robotics, automation, servo axes, packaging.

## DFM (small workshop)
Use commercial units; set release torque above normal; inspect after trips.
