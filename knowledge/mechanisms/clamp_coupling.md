# clamp_coupling

**Type:** coupling
**Function:** Lock shafts without keyways using a two-piece clamp or tapered bushing (Taper-Lock/QD).

## How it works
Radial screws or tapered bushing lock hub to shaft via friction, providing zero backlash and concentric mounting. No keyway damage.

## Key dimensions / equations
- Clamping force from screw torque/taper.
- Torque capacity from friction interface.
- Bore size limits capacity.

## Constraints
- Rigid (no misalignment).
- Bore size limits.
- Proper torque on screws needed.

## Failure modes
- Slippage if under-torqued.
- Fretting.
- Screw/bushing damage.

## When to use
Servo/precision drives, pulley/sprocket mounting, keyless connections.

## DFM (small workshop)
Use Taper-Lock/QD bushings; follow torque specs; keep bores clean.
